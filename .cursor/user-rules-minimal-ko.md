# Cursor 유저 룰 — 최소 권장본 (convert2video)

**쓰는 곳**: Cursor 설정 → **Rules for AI** (User Rules)에 아래 블록을 붙여넣기.  
**목적**: 프로젝트 룰 `convert2video-core.mdc`와 **중복 제거**.

---

다음을 따른다.

1. **언어**: 항상 한국어. 짧고 쉬운 말. 코드 블록과 설명은 구분한다.
2. **충돌**: 사용자 명령이 다른 룰과 겹치면 **사용자 요청을 우선**한다.
3. **코드 인용**: 워크스페이스 파일은 ` ```시작줄:끝줄:경로 ` ` 형식으로 인용한다. (펜스는 단독 줄)
4. **실행**: 실제 환경에서 직접 명령을 실행해 조사·해결한다. 실패 시 대안을 시도한다. 사용자에게만 맡기지 않는다.
5. **파일 생성·삭제**: 새 파일/폴더 추가나 삭제가 필요하면 **먼저 사용자에게 확인**한다.
6. **프로젝트 규칙**: Kotlin·용어·답변 마무리·에러 표시·재발방지는 **`.cursor/rules/convert2video-core.mdc`** 와 **`rules-index-kotlin.mdc`** 목차를 따른다. 같은 내용을 유저 룰에 반복하지 않는다.
7. **코드 변경**: 요청 범위만 수정한다. 주변 스타일에 맞춘다.
8. **스프린트·Harness**: 채팅에 **「스프린트 돌려」「루프 시작」**, **`@기획서`+실행**, 또는 **`/sprint-run`** 이면 **첫 답에 Harness Gate 표**를 넣고, 메인이 `app/**`를 직접 고치지 않고 **Task(planner → generator ↔ evaluator)** 만 돌린다. **기획서가 있어도** planner·evaluator 생략 금지. **evaluator PASS** + **최소 3라운드** 전에 「완료」라고 하지 않는다. (`.cursor/rules/sprint-harness-gate.mdc`)

검증까지 할 턴에는 채팅에서 **`/kotlin-verify`** 커맨드를 실행한다(컴파일·선택 린트·셀프체크·답변 형식). **스프린트 구현 턴**은 **`/sprint-run`** 을 우선한다. 평소 짧은 수정만 할 때는 커맨드 없이 진행해도 된다.

Harness 규칙·훅 변경 후 1회: `scripts\verify-harness-setup.ps1` 실행.
